## 🧩 About

**Monster Hunter Wilds Companion** is a curated list of Monster Hunter Wilds open-source tools:

- **Overlays** — on-screen helpers, layout notes, monster health viewer, map markers
- **Quality-of-Life Helpers** — item box organizer, loadout notes, overlay notes
- **Research Notes** — hunt routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Hunt Helpers
- Monster Health Overlay — track monster health and stamina
- Map Marker Notes — mark resource nodes and monster locations
- Hunt Timer — record and review hunt times
- Playback Speed — adjust game speed for study (0.1x to 5x)

### 🎒 Inventory & Gear
- Item Box Organizer — sort and manage items
- Loadout Notes — save and share gear sets
- Resource Tracker — track crafting materials

### 🏋️ Practice Layout
- Training Area Notes — practice combos on any weapon
- Wirebug Control — manual wirebug cooldown notes
- Dodge Buffer Notes — chain complex maneuvers
